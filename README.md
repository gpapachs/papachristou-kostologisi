# Κοστολόγηση — Ψητοπωλείο Παπαχρήστου

Εφαρμογή κοστολόγησης πιάτων: πρώτες ύλες με τιμές αγοράς, συνταγές (και ενδιάμεσα όπως σάλτσες/μαρινάδες), food cost %, μικτό κέρδος, προτεινόμενη τιμή και μαζική ενημέρωση τιμών με προεπισκόπηση της επίπτωσης.

Στατική εφαρμογή για **GitHub Pages** — χωρίς server, χωρίς μυστικά κλειδιά. Η βάση είναι μέσα στο Supabase project **«Κρατήσεις»** (πίνακες `kost_`), εντελώς ξεχωριστή από τις κρατήσεις.

**Ρόλοι**
- **Διαχειριστής**: τα πάντα.
- **Προσωπικό**: βλέπει μόνο συνταγές, δοσολογίες και οδηγίες (με κλιμάκωση μερίδων και εκτύπωση). Οι τιμές αγοράς είναι κλειδωμένες στη βάση — δεν φτάνουν καν στη συσκευή του.

## Εγκατάσταση (μία φορά)

1. **Βάση** — ✅ έχει γίνει ήδη (τα `supabase/*.sql` μένουν για αναφορά).
2. **GitHub** → νέο repository, π.χ. `papachristou-kostologisi` (Public).
   → *Add file → Upload files* → ανέβασε **όλα** τα περιεχόμενα του zip → *Commit*.
3. **Έλεγξε ότι ανέβηκε ο φάκελος `.github`** (ξεκινά με τελεία, και ο υπολογιστής μπορεί να τον κρύβει).
   Αν δεν φαίνεται στο repo: *Add file → Create new file*, γράψε για όνομα `.github/workflows/deploy.yml`, επικόλλησε το περιεχόμενο του αρχείου από το zip → *Commit*.
4. Repo → **Settings → Pages → Source: GitHub Actions**.
5. Στην καρτέλα **Actions** θα τρέξει το «Deploy στο GitHub Pages» (~2 λεπτά). Αν είχε τρέξει πριν το βήμα 4 και απέτυχε, πάτα *Re-run jobs*.
6. Άνοιξε `https://gpapachs.github.io/papachristou-kostologisi/` → θα σε πάει στην **Αρχική ρύθμιση** για τον λογαριασμό διαχειριστή. Η σελίδα κλειδώνει μετά.
7. Από **Χρήστες** φτιάχνεις λογαριασμούς για το προσωπικό.

## Ενημέρωση
Ανεβάζεις τα αλλαγμένα αρχεία στο GitHub — ξαναχτίζεται μόνο του. Η έκδοση φαίνεται κάτω αριστερά (`lib/version.ts`).

## Πώς υπολογίζει

- **Ωφέλιμο κόστος υλικού** = τιμή αγοράς ÷ απόδοση. Π.χ. λαιμός 6,00 €/kg με απόδοση 80% → 7,50 €/kg πραγματικό.
- **Κόστος μερίδας** = άθροισμα γραμμών ÷ μερίδες που βγάζει η συνταγή.
- **Food cost %** = κόστος μερίδας ÷ (τιμή καταλόγου ÷ (1 + ΦΠΑ)).
- **Προτεινόμενη τιμή** = κόστος ÷ στόχος % × (1 + ΦΠΑ), στρογγυλεμένη προς τα πάνω στα 10 λεπτά.
- Τα ενδιάμεσα (π.χ. τζατζίκι ανά kg) μπαίνουν σε πιάτα σαν υλικό· όταν αλλάζει η τιμή του γιαουρτιού, αλλάζει αυτόματα και το κόστος κάθε πιάτου με τζατζίκι.

## Ασφάλεια
Το κλειδί στο `lib/config.ts` είναι δημόσιο (publishable) — είναι φτιαγμένο για να βρίσκεται στον browser. Την προστασία την κάνουν οι κανόνες της βάσης: οι τιμές διαβάζονται μόνο από διαχειριστή, και οι συναρτήσεις `kost_admin_*` ελέγχουν ρόλο και αγγίζουν μόνο χρήστες της κοστολόγησης (ποτέ το προσωπικό των Κρατήσεων).
